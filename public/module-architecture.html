Authentication — Two Systems
Sanctum Bearer tokens (API) + Web session (SSO for legacy modules)
🔑
API Auth — Sanctum Bearer
POST /api/auth/login → { token }. Stored in localStorage as auth_token. Sent as Authorization: Bearer on every Axios request. Logout deletes token from DB and localStorage.
🌐
Web Session Auth — Module SSO
Legacy modules need web session. GET /plugins/sso?token=X → auth('web')->loginUsingId(userId) → session regenerate → redirect to module page. One-time token, valid 1 minute in Cache.

Permission Check — User::hasPermission() — 5 levels

1. user.role === 'admin'          → always true (legacy column)
2. role relationship.slug === 'admin'  → always true
3. role.permissions (JSON array)  → check key or nested match
4. user.roles many-to-many        → role_permissions → permissions.name
5. direct role.permissions()      → permission name lookup

Backend Boot — ModuleServiceProvider
Runtime dynamic registration of every active module on every Laravel request
// app/Providers/ModuleServiceProvider.php (157 lines)
// Called on EVERY request — both register() and boot()

getActiveModules():
  // Safe guard: Schema::hasTable('modules') before querying
  DB::table('modules')->where('status', 'active')->get(['name', 'alias'])

register():
  // Get Composer class loader at runtime
  $loader = require base_path('vendor/autoload.php')

  // For each active module:
  // Convert alias/name → PascalCase namespace
  // "my-custom-module" → "MyCustomModule"
  // "HR Payroll" → "HRPayroll"
  $nsPrefix = str_replace(' ', '', ucwords(str_replace(['-','_'], ' ', $alias)))
  // If alias starts with digit, prefix with "Mod_"

  // Register PSR-4 at runtime — NO composer dump-autoload needed!
  $loader->addPsr4("Modules\\{$nsPrefix}\\", "Modules/{$alias}/")
  // Falls back to name-based dir if alias-based doesn't exist (legacy)

boot():
  // Web routes (checks both routes/ and Routes/ for case-sensitivity)
  Route::middleware('web')
    ->namespace("Modules\\{$nsPrefix}\\Controllers")
    ->group("Modules/{$alias}/routes/web.php")

  // API routes
  Route::middleware('api')->prefix('api')
    ->namespace("Modules\\{$nsPrefix}\\Controllers\\Api")
    ->group("Modules/{$alias}/routes/api.php")

  // Blade views
  $this->loadViewsFrom("Modules/{$alias}/Views", strtolower($alias))

  // Migrations
  $this->loadMigrationsFrom("Modules/{$alias}/Database/Migrations")

KEY: Only ACTIVE modules are registered. Deactivate = routes/autoload removed next request.
SAFE: Schema::hasTable guard prevents crash during fresh install migrations.

Complete Module Install Flow
ModuleController → ModuleManager — every step from ZIP to active module
// POST /api/plugins → ModuleController@store

1. VALIDATE:  $request->validate(['module_file' => 'required|file|mimes:zip'])
2. STORE:     storage/app/temp_uploads/{filename}.zip
3. INSTALL:   ModuleManager::install($fullTempPath)

  EXTRACT:
  ZipArchive → storage/app/temp_module_extract_{microtime}_{uniqid}/

  FIND MANIFEST (4 strategies):
  a) Find module.json anywhere in extracted tree → json_decode
  b) Find PHP files with WordPress/Perfex comment headers
     ("Module Name:", "Version:", "Author:", "Requires at least:")
  c) Find nested .zip files (CodeCanyon double-zip) → re-extract → try a+b
  d) None found → Exception "Invalid module ZIP"

  NORMALIZE alias:
  strtolower → preg_replace(/[^a-z0-9]+/, '-') → trim hyphens

  DUPLICATE CHECK:
  Module::where('alias', $alias)->first()
  Found?  → ModuleManager::upgrade($existing, $zipPath)  [version must be higher]
  Not found? → continue install

  VALIDATE MANIFEST:
  - name, alias required
  - version → normalize X.Y.Z (fill missing parts with 0)
  - minimum_core_version (core assumed = 3.0.0)

  COPY FILES:
  File::copyDirectory($moduleDir, base_path("Modules/{$alias}"))
  File::deleteDirectory($tempDir)

  AUTO-MIGRATE LEGACY VUE FILES:
  skeleton/resources/js/views/module/*.vue
  → Parse filename (PascalCase) → strip module prefix → snake_case
  → Match to menu.json routes
  → Copy to resources/js/pages/{matched_route}.vue (no overwrite)

  CREATE DB RECORD:
  Module::create([name, alias, version, depends, status='installed', ...])

  RUN LEGACY CI INSTALLER:
  Define globals: BASEPATH, db_prefix(), get_staff_user_id(), get_instance()
  $CI->db->query() → rewrites tbl_modules→modules, active=1→status='active'
  $CI->db->table_exists() → Schema::hasTable()
  Run: Modules/{alias}/install.php
  Scan: Modules/{alias}/migrations/*.php → class Migration_* → ->up()

  RUN LARAVEL MIGRATIONS:
  Artisan::call('migrate', ['--path' => 'Modules/{alias}/Database/Migrations'])

  FLUSH CACHE + FIRE EVENT: ModuleInstalled

4. AUTO-ACTIVATE:   ModuleManager::activate($module->id)

  DEPENDENCY CHECK:
  foreach ($depends as $dep) → Module::where('alias',$dep)->where('status','active')->exists()

  HEALTH CHECK:  is_dir("Modules/{$alias}")

  DB TRANSACTION:
  a) Read permissions.json:
     - Permission::firstOrCreate(['name' => $key])
     - ModulePermission::create([module_id, permission_name])
     - Admin role → DB::table('role_permissions')->insertOrIgnore([role_id, permission_id])

  b) Read menu.json → registerMenuNode() recursive:
     ModuleMenu::create([module_id, parent_id, title, route, icon, permission])
     foreach children → registerMenuNode(moduleId, child, $menuNode->id)
     [No menu.json → auto-generate from Views/ subfolder names]

  c) modules.status = 'active', activated_at = now()

  FIRE EVENT: ModuleActivated

5. CLEANUP:  unlink($fullTempPath)
6. RESPONSE: 201 { success: true, message: "Plugin uploaded, installed, activated" }

menus() API — Exact Response Structure
GET /api/plugins/menus — how DB data becomes sidebar items
// ModuleController@menus — GET /api/plugins/menus

$activeModules = Module::where('status', 'active')->get()

foreach ($activeModules as $mod) {
  $rootMenus = ModuleMenu::where('module_id', $mod->id)->whereNull('parent_id')->get()

  foreach ($rootMenus as $root) {
    // Root permission gate
    if ($root->permission && !$user->hasPermission($root->permission)) continue;

    $children = ModuleMenu::where('parent_id', $root->id)->get()
      ->filter(fn($c) => !$c->permission || $user->hasPermission($c->permission))
      ->map(fn($c) => [
        'name' => ModuleManager::formatMenuTitle($c->title),
        'path' => "/admin/module/{$mod->alias}" . $c->route,
      ]);

    $menuList[] = [
      'name'     => ModuleManager::formatMenuTitle($root->title),
      'icon'     => $root->icon,
      'path'     => $root->route ? "/admin/module/{$alias}" . $root->route : null,
      'children' => !empty($children) ? $children->values()->toArray() : null,
      'dynamic'  => true,
      'slug'     => $mod->alias,
    ];
  }
}

// ModuleSettingsService (240 lines)

Schema loading:

Schema structure:
  { "sections": [{ "title": "...", "fields": [{
    "key": "api_key",        // storage key + validation identifier
    "label": "API Key",      // UI label
    "type": "password",      // field type (see 13 types below)

    "width": 24,             // Ant Design grid col span (1–24)
    "help": "hint text",     // help text below field
    "validation": { "required": true }
  }]}]}

Value encoding (setting_value in DB):
  multiselect → json_encode($value)
  password    → encrypt((string)$value)      ← Laravel encrypt()
  others      → (string)$value

Value decoding (reading from DB):
  multiselect → json_decode → array
  number      → (float)
  boolean     → in_array($val, ['1',1,'true',true])
  password    → decrypt($value) catch → raw value
  others      → raw string
